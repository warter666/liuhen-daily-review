# 留痕计划 · 每日总结复盘

> 每一天，都值得被记录。

一个**单文件、零依赖、纯本地**的每日总结复盘网站。打开即用，数据存在你自己的浏览器里。
整体采用 Apple 官网式简约设计：灰白底色、磨砂玻璃导航、大标题大留白、苹果蓝唯一强调色。

## ✨ 功能

### 📝 每日复盘
- 四个问题，五分钟记录一天：**今天完成了什么 / 收获与思考 / 问题与改进 / 明日三件事**
- 今日状态快选（😣 → 🚀 四档心情）
- 同一天重复提交自动覆盖，支持编辑与删除历史记录

### 📊 数据看板
- 累计留痕、连续天数、本周留痕、近期状态一览

### 🗂 留痕时间线
- 所有记录按日期倒序展示的卡片流
- 一键导出 **JSON** / **Markdown**，支持导入合并，数据随时带走

### 👻 幽影小跟班
- 瓦洛兰特「幽影（Omen）」Q 版大头，从页面加载起常驻屏幕
- 以 **0.3 秒延迟**严格回放你的鼠标轨迹（轨迹点插值，走原路而非直线追赶）
- 移动中斗篷飘动、身体倾斜、自动转向，停下后漂浮待机、眨眼发光

### 🎯 靶场反应训练
- 瓦洛兰特风格的训练机器人随机刷新在屏幕**两侧**，十字准星点击命中
- 命中即爆、随机 0.6–3 秒后随机重生
- 左下角 HUD 实时显示：击中数、训练用时、**目标存活时间**、上次 / 平均 / 最快反应
- 当天数据自动保存，按日期重置

## 🚀 使用

无需安装任何东西，直接用浏览器打开 `index.html` 即可。

也可以用 GitHub Pages 在线访问（仓库公开时）：

```
https://warter666.github.io/liuhen-daily-review/
```

## 🛠 技术

- 单个 `index.html`，HTML + CSS + 原生 JavaScript，**零依赖、零构建**
- 数据持久化：`localStorage`（复盘记录 `liuhen.entries`、靶场战绩 `liuhen.range`）
- 卡通形象与机器人均为内联 SVG 手绘，无外部图片资源
- 滚动渐显使用 `IntersectionObserver`，轨迹回放基于时间戳插值 + `requestAnimationFrame`
